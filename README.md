# Student Registration & Result Management System
**Fullstack Assignment | MCA Semester 1**

## 📝 Project Description
This is a responsive Student Management application. It takes student marks as input, processes the data using JavaScript logic, and stores the results in the browser's LocalStorage using JSON.

## 🛠️ Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Flexbox and Responsive Design.
- **JavaScript (ES6):** Logic and DOM Manipulation.
- **JSON & LocalStorage:** Client-side data persistence.

## ⚙️ Logic Implemented
1. **Validation:** Checks if marks are between 0-100.
2. **Calculations:** Auto-calculates Total and Percentage.
3. **Storage:** Converts objects to JSON strings for persistent storage.
4. **CRUD:** User can add and delete student records.
